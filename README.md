# 🎮 X-O Arena

**Think smart. Make your move. Win the arena.**

X-O Arena is a desktop game inspired by the classic XO (Tic-Tac-Toe) experience, built with Electron.

## ✨ About the Game

Enjoy a classic XO gaming experience in a desktop application for Windows.

## 📥 Download & Install

**[Download X-O Arena](https://github.com/icyr4zo/X-O-Arena/releases/latest)**

1. Open the Releases page using the link above.
2. Download `X-O-Arena-1.0.0.Setup.exe` from the latest release.
3. Run the installer and follow the on-screen instructions.
4. Launch X-O Arena and enjoy the game!

If Windows displays a security warning, make sure you downloaded the installer from this official repository before deciding whether to run it.

## ⚠️ Windows Security Notice

When downloading and running the installer, Windows may block the file because it was downloaded from the Internet.

If you trust the file and have verified that it was downloaded from the official [XO Arena GitHub Releases](https://github.com/icyr4zo/X-O-Arena/releases/latest), follow these steps:

1. Right-click `X-O-Arena-1.0.0.Setup.exe`.
2. Select **Properties**.
3. Under the **General** tab, look for the **Unblock** checkbox.
4. If the option is available, check **Unblock**, then click **Apply** and **OK**.
5. Run the installer again.

**Note:** Only unblock files downloaded from a source you trust. Do not disable Windows Defender or other security protections.
