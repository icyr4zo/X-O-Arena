## 🕹️ About the Project

**X-O Arena** is a personal game development project inspired by the classic XO game. The project focuses on bringing a familiar strategy game into a dedicated desktop application.

Whether you're exploring the project as a player or looking through the code as a developer, X-O Arena represents an ongoing journey in game development and software engineering.
